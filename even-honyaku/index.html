IGNORE MY OWN VOICE

When you speak Japanese (for example reading a suggested reply aloud), Honyaku should not translate it or answer it. It tells you apart from the other person by the words (a reply it just suggested), how loud you are at the glasses mic, and your voice profile.

MY VOICE PROFILE

SETUP

Two keys and you are done. They are your own accounts, so usage is billed to you.

  1. Deepgram keyspeech-to-text
  2. One translation keyGoogle, OpenRouter or Claude

SPEECH-TO-TEXT

  1. Go to console.deepgram.com and sign up (new accounts get free credit).
  2. Open your project, then API Keys → Create a New API Key.
  3. Name it "Honyaku" and leave the default (Member) access.
  4. Copy the key right away (Deepgram shows it only once) and paste it here.
billed per minute of audio to your Deepgram account

TRANSLATION

  1. Go to console.cloud.google.com, create or pick a project and turn on billing (the first 500,000 characters a month are free).
  2. Open APIs & Services → Library, search Cloud Translation API and press Enable.
  3. Open APIs & Services → Credentials → Create credentials → API key.
  4. Edit the key and set API restrictions → Restrict key → Cloud Translation API. Do not add website restrictions: the app has no fixed address.
  5. Copy the key and paste it here.
  1. Go to openrouter.ai and sign in.
  2. Open Credits and add a few dollars. Models are billed per token and a phrase costs a fraction of a cent.
  3. Open Keys → Create Key, name it "Honyaku" and optionally set a spending limit.
  4. Copy the key and paste it here. The model is optional; the default is fast and cheap.
  1. Go to console.anthropic.com and sign in.
  2. Open Plans & Billing and add credits. The API is billed per token, separately from a Claude chat subscription.
  3. Open API Keys → Create Key and name it "Honyaku".
  4. Copy the key right away (it is shown only once) and paste it here.
