IGNORE MY OWN VOICE

When you speak Japanese (for example reading a suggested reply aloud), Honyaku should not translate it or answer it. It tells you apart from the other person by the words (a reply it just suggested), how loud you are at the glasses mic, and your voice profile.

higher treats a voice as yours more readily. Still translating your own Japanese? raise it. Missing what they say? lower it.

MY VOICE PROFILE

Put the glasses on and read each sentence at your normal volume, the way you would really say it (accent and all). It takes about a minute. The voice profile stays on this phone and is never sent anywhere.

SPEECH-TO-TEXT

  1. Go to console.deepgram.com and sign up (new accounts get free credit).
  2. Open your project, then API Keys → Create a New API Key.
  3. Name it "Honyaku" and leave the default (Member) access.
  4. Copy the key right away (Deepgram shows it only once) and paste it here.
billed per minute of audio to your Deepgram account

TRANSLATION

  1. Go to console.cloud.google.com, create or pick a project and turn on billing (the first 500,000 characters a month are free).
  2. Open APIs & Services → Library, search Cloud Translation API and press Enable.
  3. Open APIs & Services → Credentials → Create credentials → API key.
  4. Edit the key and set API restrictions → Restrict key → Cloud Translation API. Do not add website restrictions: the app has no fixed address.
  5. Copy the key and paste it here.
  1. Go to openrouter.ai and sign in.

  4. Copy the key and paste it here. Then pick a model below: the top choice is recommended and costs a fraction of a cent per phrase.

      HONYAKU

      CONTROLS

      ON THE GLASSES

      Tap
      Pause or resume listening. The mic is closed while paused, so nothing is streamed or billed.
      Double tap
      Exit. The glasses ask you to confirm; answer No and everything keeps working.
      Tap, then long press
      Opens the glasses' own menu, with Honyaku's items added: Pause / Resume, Mode, Replies, Options, Voice filter and Kana. Move with a swipe, pick with a tap. The page redraws after a change, and the menu shows the new value next time you open it.
      Swipe up / down
      Standard mode: scroll the feed one translation at a time. Predictive mode: move the ▶ highlight along the suggested replies; swipe up past the first one to read earlier turns, down to come back.
      Plain long press
      Not used, so it stays free for your own shortcut.

      ON THE PHONE

      Hold the big button
      Talk English while you hold it. Let go and the romaji to read aloud appears.
      Resume / Pause listening
      Same as a tap on the glasses.
      Type to translate
      Type a phrase in English or Japanese instead of speaking it.

      READING THE GLASSES

      JP: …
      What the other person said, in English. JP? means the voice filter wasn't sure it was them.
      you: …
      What you said in English, with the romaji to read aloud under it.
      ▶ and ●
      Predictive replies: ▶ marks the highlighted reply, ● marks the one you read aloud.
      ○ paused / ● listening
      The header shows whether the mic is on.
